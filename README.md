Binary Arithmetic and Rotation Operations

📌 Project Description

This project implements binary arithmetic and bit rotation operations using Python. It demonstrates signed binary arithmetic, left rotation, and left rotation with carry.

🎯 Objectives

- Understand binary number representation.
- Perform signed binary arithmetic.
- Implement left rotation on an 8-bit binary number.
- Implement left rotation with carry.
- Display intermediate and final results.

🛠️ Technologies Used

- Programming Language: Python
- Editor: Visual Studio Code
- Version Control: Git and GitHub

📂 Project Structure

Binary-Arithmetic/
├── assignment_1&2.py
└── README.md

▶️ How to Run the Program

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the Python file.
4. Open the terminal.
5. Run the following command:

python "assignment_1&2.py"

🧪 Operations Implemented

1. Signed Binary Arithmetic

Performs arithmetic operations using signed binary numbers.

2. Left Rotation

Rotates the bits of an 8-bit binary number to the left.

3. Left Rotation with Carry

Performs left rotation while tracking the carry bit after each rotation.

💻 Sample Output

Original: 10110110
Initial carry: 0
After rotation 1: 01101100 Carry: 1
After rotation 2: 11011001 Carry: 0
Final result: 11011001
Final carry: 0
